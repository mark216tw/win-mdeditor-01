# 使用指南

本文件說明 Markdown 編輯器（MdEditor）的安裝、介面操作、功能與疑難排解。若想了解內部設計，請見 [系統架構](系統架構.md)、[技術文件](技術文件.md) 與 [系統設計](系統設計.md)。

## 1. 安裝與啟動

### 1.1 系統需求

- Windows 10 1809（build 17763）以上或 Windows 11
- x64 或 ARM64 架構

### 1.2 必要執行環境

本專案發行的是**非 Self-Contained** 版本，請先安裝：

1. [.NET 10 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（與 App 相同架構）
2. [Windows App Runtime 1.8](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads)（與 App 相同架構）
3. [Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)

### 1.3 啟動

1. 從 [Releases](https://github.com/mark216tw/win-mdeditor-01/releases) 下載 `MdEditor-<版本>-win-x64.zip` 或 `MdEditor-<版本>-win-arm64.zip`。
2. 解壓縮到任意資料夾。
3. 執行 `MdEditor.exe`。

App 不需要系統管理員權限。也可以帶入檔案路徑啟動：

```powershell
MdEditor.exe "D:\docs\note.md"
```

若已有開啟中的視窗，第二個實例會把檔案轉送到既有視窗。

## 2. 介面導覽

```text
┌──────────────────────────────────────────────────────────┐
│ 檔案 (F)  編輯 (E)  檢視 (V)  設定 (S)                    │ 系統選單
├──────────────────────────────────────────────────────────┤
│ B I S </> │ H1 H2 H3 │ 清單 … │ 連結 …       [檢視：並排] │ 工具列
├──────────────────────────────────────────────────────────┤
│ 文件1 ✕ │ 文件2 * ✕                                        │ 頁籤
├───────────────────────────┬──────────────────────────────┤
│ 編輯器（CodeMirror 6）     │ 預覽（Markdig HTML）         │
│                           │                              │
├───────────────────────────┴──────────────────────────────┤
│ 行 1，欄 1 │ 0 字 │ UTF-8 │ LF │ 已儲存            [📁]   │ 狀態列
└──────────────────────────────────────────────────────────┘
```

### 2.1 系統選單

- **檔案 (F)**：新增、開啟、儲存、另存新檔、儲存全部、最近開啟、匯出 PDF／Word、關閉文件、結束程式。
- **編輯 (E)**：復原、重做、全選、尋找／取代。
- **檢視 (V)**：編輯／預覽／並排、自動換行、字型放大／縮小／重設。
- **設定 (S)**：偏好設定、關於。

### 2.2 工具列

- 格式按鈕以分隔線分成「行內格式／標題／清單與區塊／插入」四組。
- 最右側為「編輯／預覽／並排」循環切換按鈕。
- 視窗變窄時，格式按鈕可橫向捲動，檢視按鈕仍固定在最右側。

### 2.3 頁籤

- 每個開啟的文件都是一個頁籤。
- 檔名後的 `*` 表示尚未儲存。
- 頁籤右側的 `✕` 或滑鼠中鍵可關閉該文件；有未儲存變更時會詢問。
- 在頁籤上按右鍵可「關閉」、「關閉其他文件」、「複製完整路徑」或「在檔案總管中顯示」。

### 2.4 狀態列

顯示游標位置、字數、編碼、換行格式與儲存狀態。右側的資料夾按鈕可開啟目前檔案所在位置；滑鼠移入會顯示完整路徑。

## 3. 開啟、儲存與關閉

| 操作 | 方式 |
| --- | --- |
| 開啟 | `Ctrl+O`、拖放檔案到視窗、或從系統選單「檔案 → 開啟」 |
| 新增 | `Ctrl+N` |
| 儲存 | `Ctrl+S` |
| 另存新檔 | `Ctrl+Shift+S` |
| 儲存全部 | 「檔案 → 儲存全部」 |
| 關閉文件 | `Ctrl+W`、頁籤上的 `✕` 或頁籤中鍵 |
| 結束程式 | 「檔案 → 結束程式」或視窗關閉鈕 |

- 關閉有未儲存變更的文件時，可選擇儲存、不儲存或取消。
- 關閉程式時不會詢問是否儲存；未儲存的內容仍會保留在暫存中，下次開啟會自動還原。

## 4. 檢視模式

- `Ctrl+1`：編輯
- `Ctrl+2`：預覽
- `Ctrl+3`：並排

也可以從「檢視」選單切換。並排模式下可拖曳中間的分隔線調整比例；滑鼠移入時會顯示左右調整游標。檢視模式會保存，下次啟動沿用。

## 5. Markdown 編輯

- 編輯器使用 CodeMirror 6，提供 Markdown 語法高亮、括號配對與搜尋。
- `Ctrl+B` 粗體、`Ctrl+I` 斜體。
- 編輯器內按 `Ctrl+F` 使用搜尋／取代面板（介面為繁體中文）。
- `Ctrl+=`／`Ctrl+-`／`Ctrl+0` 可放大、縮小、重設字型，也可從「檢視」選單操作。
- 在編輯器或預覽上使用 `Ctrl+滑鼠滾輪` 也能調整字型；兩邊會同步。
- 「檢視 → 自動換行」可切換自動換行；設定會保存。
- 工具列按鈕會依目前選取範圍插入或包覆 Markdown 語法。

## 6. 預覽

- 預覽由 Markdig 產生 HTML，支援 GFM 表格、工作清單、程式碼區塊與語法高亮。
- 程式碼區塊右上角提供「複製」按鈕。
- 本機相對路徑圖片會經由 `https://doc.local/` 對應載入；遠端圖片基於安全考量預設不載入。
- 預覽中的連結會交由系統瀏覽器開啟。
- 在預覽上使用 `Ctrl+滑鼠滾輪` 可調整字型，並與編輯器同步。

### 6.1 數學公式

以 KaTeX 在預覽中排版，支援常見 LaTeX 語法：

```markdown
行內公式：$E = mc^2$

區塊公式：

$$
\int_0^1 x^2 \, dx
$$
```

- 貨幣寫法（例如 `$5`）可能被誤判為數學公式，請用 `\$` 跳脫。
- 若語法無法解析，會保留原始 LaTeX 文字，不會中斷預覽。

### 6.2 流程圖與圖表

使用 Mermaid 語法，支援流程圖、時序圖、類別圖、狀態圖、甘特圖等：

````markdown
```mermaid
flowchart TD
  A[開始] --> B{條件成立？}
  B -->|是| C[完成]
  B -->|否| D[調整]
```
````

- 圖表會跟隨目前主題重新繪製。
- 語法錯誤時會顯示錯誤訊息與原始碼，方便修正。
- 圖表與公式都會一併輸出到 PDF；Word 匯出目前不支援排版。

## 7. 外觀與偏好設定

按 `Ctrl+,` 或「設定 → 偏好設定」開啟，可設定：

- **主題**：跟隨系統（預設）、淺色、深色、護眼、晨光、薰衣草、北歐藍、森林綠、高對比。
- **同步捲動**：在並排檢視中捲動編輯器時，預覽會同步捲動到相同比例（預設啟用）。
- **自動換行**：編輯器是否自動換行（預設啟用）。
- **字型大小**：10–28（預設 14），同時套用到編輯器與預覽。
- **檔案關聯**：登錄或解除 `.md`、`.markdown`，並開啟 Windows「預設應用程式」設定。

字型大小也可在編輯器或預覽上以 `Ctrl+滑鼠滾輪` 快速調整；PDF 匯出固定使用 11pt。

主題會即時套用至 WinUI 外殼、對話框、編輯器與預覽；選擇「跟隨系統」時，切換系統淺色／深色也會即時更新。

## 8. 檔案關聯

1. 開啟「設定 → 偏好設定」。
2. 在「檔案關聯」按「登錄並開啟預設應用程式設定」，或直接將開關切到「已登錄」後按「儲存」。
3. Windows 會開啟「預設應用程式」設定頁，請在該處選擇「Markdown 編輯器」。

注意：

- Windows 不允許程式自行設定預設，必須由使用者手動選擇一次。
- 登錄只寫入目前使用者（HKCU），不需要系統管理員權限。
- 在偏好設定將開關切回「未登錄」並儲存，即可移除登錄。
- 程式搬移位置後，登錄的開啟命令會失效，請重新登錄。

## 9. 自動暫存與工作階段還原

- 編輯內容會在停止輸入約 1.5 秒後自動寫入暫存。
- 切換分頁、關閉文件、關閉程式前會再儲存一次。
- 下次啟動時會還原：
  - 開啟的文件與未儲存內容
  - 使用中的分頁
  - 編輯／預覽／並排檢視模式
- 從 App 關閉文件時，會同步刪除該文件的暫存。
- 暫存只保留目前工作階段，不提供版本歷史或多份舊版。

## 10. 最近開啟

- 「檔案 → 最近開啟」會列出最近開啟的檔案，單擊即可開啟。
- 子選單底部可「釘選目前檔案／取消釘選目前檔案」或「從最近開啟移除目前檔案」。
- 已釘選的檔案會排在清單上方；也可清除整個清單。
- 檔案不存在時會標示為遺失。

## 11. 外部檔案變更

若檔案在 App 外被修改，視窗上方會顯示提示：

- 按「重新載入」可重新讀取檔案。
- 若目前有未儲存變更，會先詢問是否覆蓋。
- 檔案被刪除或重新命名時也會提示。

## 12. 匯出

### PDF

「檔案 → 匯出 → 匯出 PDF...」，使用 WebView2 `PrintToPdfAsync` 輸出固定 A4、直向、含背景色彩的 PDF。

### Word

「檔案 → 匯出 → 匯出 Word (.docx)...」，使用 OpenXML 產生 `.docx`，不需要安裝 Microsoft Word。遠端圖片不會嵌入，只會處理本機相對路徑圖片。數學公式會以 LaTeX 原文呈現，Mermaid 圖表會以程式碼區塊呈現，尚不支援排版後的內容。

## 13. 編碼與換行

- 開啟時自動偵測 BOM：UTF-8、UTF-16 LE／BE、UTF-32 LE／BE。
- 無 BOM 時先嘗試嚴格 UTF-8；失敗則使用系統 ANSI 代碼頁。
- 儲存時保留原編碼、BOM 與主要換行格式（LF／CRLF）。
- 寫入採「暫存檔 + 原子替換」，降低寫入中斷造成檔案毀損的風險。

## 14. 資料位置與重設

| 內容 | 路徑 |
| --- | --- |
| 設定與最近檔案 | `%LocalAppData%\MdEditor\settings.json` |
| 工作階段暫存 | `%LocalAppData%\MdEditor\drafts\` |
| 記錄檔 | `%LocalAppData%\MdEditor\logs\log-yyyyMMdd.txt` |

- 重設設定：關閉程式後刪除 `settings.json`。
- 清除暫存：關閉程式後刪除 `drafts\` 資料夾。
- 刪除整個 `%LocalAppData%\MdEditor` 可完整重設（不會刪除你的 Markdown 檔案）。
- 視窗大小、位置與最大化狀態會保存在 `settings.json`，下次啟動時還原；若原本的螢幕已不在，會自動調整到可見範圍。

## 15. 疑難排解

| 症狀 | 處理方式 |
| --- | --- |
| 啟動後顯示「請確認已安裝 Microsoft Edge WebView2 Runtime」 | 安裝 WebView2 Evergreen Runtime，或確認 `Assets` 資料夾完整 |
| 啟動失敗並提示找不到 .NET／Windows App Runtime | 安裝對應架構的 .NET 10 Runtime 與 Windows App Runtime 1.8 |
| 檔案關聯沒有出現在「開啟方式」 | 重新登錄；確認 `.md`／`.markdown` 未被其他程式以 UserChoice 鎖定 |
| 已登錄但無法變成預設 | 這是 Windows 限制，請在「預設應用程式」設定頁手動選擇 |
| 預覽圖片不顯示 | 遠端圖片預設被封鎖；本機圖片請確認相對路徑與檔案存在 |
| 數學公式顯示為原始 LaTeX | 確認使用 `$...$` 或 `$$...$$`；貨幣符號請以 `\$` 跳脫 |
| 流程圖沒有畫出來 | 確認程式碼區塊語言標記為 `mermaid`，並檢查錯誤訊息中的語法提示 |
| 中文檔名或路徑顯示異常 | 回報問題並附上記錄檔；請確認 Windows 版本與系統地區設定 |
| 程式移動後雙擊 `.md` 沒有反應 | 重新登錄檔案關聯 |

回報問題時請附上 `%LocalAppData%\MdEditor\logs\` 下最新的記錄檔。
