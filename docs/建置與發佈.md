# 建置與發佈

本文件說明如何從原始碼建置、測試與產生 GitHub Release 使用非 Self-Contained 套件（x64、ARM64）。

## 1. 必要工具

| 工具 | 版本 | 備註 |
| --- | --- | --- |
| Windows | 10 1809 以上或 Windows 11 | |
| .NET SDK | 10.0.403 | 以 `global.json` 為準 |
| Node.js | 20 以上 | 僅修改 `web/` 時需要 |
| Git | 近期版本 | |
| GitHub CLI（選用） | 2.x | 建立儲存庫與 Release |

開發機需安裝 Microsoft Edge WebView2 Runtime，才能執行 App。

## 2. 還原與建置

```powershell
npm --prefix web install
npm --prefix web run build
dotnet restore MdEditor.sln
dotnet build MdEditor.sln -c Debug
```

- 只修改 C# 時，可跳過 npm 指令；`src/MdEditor/Assets` 已包含 bundle。
- 開發與測試使用 `Debug`；除非要發行，不要建置 `Release`。

## 3. 測試與格式

```powershell
dotnet test tests\MdEditor.Tests\MdEditor.Tests.csproj -c Debug
dotnet format MdEditor.sln --verify-no-changes
```

合併前請確認兩者皆通過。

## 4. 版本規則

- 版本集中於 `Directory.Build.props` 的 `Version`／`AssemblyVersion`／`FileVersion`。
- `Version` 採 `主.次.修`；功能變更加次版，修正加修版。
- 每次變更同步更新 `CHANGELOG.md`、`RELEASE_NOTES.md` 與 `docs/DEV_LOG.md`。
- 本文件以 `0.10.3` 為例。

## 5. 發佈非 Self-Contained 套件

### 5.1 使用腳本（建議）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\publish-release.ps1 -Version 0.10.3
```

腳本會：

1. 依序發佈 `win-x64` 與 `win-arm64`。
2. 使用 `--self-contained false` 與 `-p:WindowsAppSDKSelfContained=false`。
3. 在輸出資料夾加入 `安裝說明.txt`。
4. 產生 `artifacts\MdEditor-0.10.3-win-x64.zip` 與 `artifacts\MdEditor-0.10.3-win-arm64.zip`。

`artifacts/` 已在 `.gitignore` 中，不會被提交。

### 5.2 手動指令

```powershell
dotnet publish src\MdEditor\MdEditor.csproj -c Release -r win-x64 `
  --self-contained false `
  -p:WindowsAppSDKSelfContained=false `
  -p:WindowsPackageType=None `
  -p:Platform=x64 -p:PlatformTarget=x64 `
  -p:Version=0.10.3 -p:AssemblyVersion=0.10.0.0 -p:FileVersion=0.10.3.0 `
  -o artifacts\win-x64

dotnet publish src\MdEditor\MdEditor.csproj -c Release -r win-arm64 `
  --self-contained false `
  -p:WindowsAppSDKSelfContained=false `
  -p:WindowsPackageType=None `
  -p:Platform=arm64 -p:PlatformTarget=arm64 `
  -p:Version=0.10.3 -p:AssemblyVersion=0.10.0.0 -p:FileVersion=0.10.3.0 `
  -o artifacts\win-arm64
```

`MdEditor.csproj` 依平台預設使用 `win-x64`／`win-arm64` 與 Self-Contained 供本機開發；Release 發佈啟用 ReadyToRun。上述指令以命令列屬性覆寫，不會修改專案檔。

### 5.3 檢查產物

```powershell
Get-Content artifacts\win-x64\MdEditor.runtimeconfig.json
Get-ChildItem artifacts\win-x64 | Measure-Object
```

確認：

- `runtimeconfig.json` 的 `framework.name` 為 `Microsoft.NETCore.App`。
- 輸出包含 `MdEditor.pri`（WinUI XAML 資源）；`EnableMsixTooling` 必須為 `true`，否則啟動時找不到主題資源。
- 輸出中沒有 `coreclr.dll`、`hostfxr.dll`、`hostpolicy.dll`（非 Self-Contained）。
- 沒有 `Microsoft.WindowsAppRuntime.dll`（Windows App SDK 由系統執行環境提供）。
- `MdEditor.exe` 架構正確（x64 或 ARM64）。

### 5.4 打包

```powershell
Compress-Archive -Path artifacts\win-x64\*   -DestinationPath artifacts\MdEditor-0.10.3-win-x64.zip
Compress-Archive -Path artifacts\win-arm64\* -DestinationPath artifacts\MdEditor-0.10.3-win-arm64.zip
```

## 7. GitHub Release

```powershell
git tag v0.10.3
git push origin v0.10.3

gh release create v0.10.3 `
  artifacts\MdEditor-0.10.3-win-x64.zip `
  artifacts\MdEditor-0.10.3-win-arm64.zip `
  --title "MdEditor v0.10.3" `
  --notes-file RELEASE_NOTES.md
```

- Release Notes 以 `RELEASE_NOTES.md` 為準，並在開頭說明必要執行環境。
- 資產只包含非 Self-Contained 的 x64 與 ARM64 zip。
- 專案採用 MIT License，GitHub 會依根目錄 `LICENSE` 自動標示。

## 9. 疑難排解

| 症狀 | 可能原因與處理 |
| --- | --- |
| `NETSDK1083`／RID 錯誤 | 確認 SDK 10 已安裝，並使用 `win-x64`／`win-arm64` |
| `Platform 'arm64' is not valid` | 直接對 csproj 發佈並帶 `-p:Platform=arm64 -p:PlatformTarget=arm64` |
| XAML Compiler 錯誤（WMC9999） | 先確認 C# 編譯無錯誤；清除 `obj/`、`bin/` 後重建 |
| 啟動缺少 DLL | 確認已安裝對應架構的 .NET 10 Runtime 與 Windows App Runtime 1.8 |
| 啟動時找不到 `ms-appx:///Styles/Themes/*.xaml` | 確認 `EnableMsixTooling=true` 且輸出含 `MdEditor.pri` |
| 編輯器或預覽空白 | 確認 `Assets/Editor`、`Assets/Preview` 存在且 WebView2 Runtime 已安裝 |
| ARM64 產物無法在 x64 執行 | 屬正常現象，需在 Windows on Arm 裝置測試 |
| 檔案關聯沒有出現在設定頁 | 重新登錄；確認 `HKCU\Software\RegisteredApplications` 有 `MdEditor` |

## 10. 附註：Self-Contained（未列入 Release）

若需要離線或受控環境，可將 `--self-contained` 改為 `true` 並加上 `-p:WindowsAppSDKSelfContained=true`。此形態會顯著增加檔案大小，且非本專案公開 Release 的內容。
